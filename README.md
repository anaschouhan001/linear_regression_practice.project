# House Price Prediction using Linear Regression

## 📌 Project Overview

A Machine Learning project that predicts house prices using **Linear Regression**. The project covers data preprocessing, exploratory data analysis, model training, prediction, and evaluation.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## 🔍 Project Workflow

1. Load and understand the dataset
2. Clean and preprocess the data
3. Perform Exploratory Data Analysis
4. Select relevant features
5. Split data into training and testing sets
6. Train the Linear Regression model
7. Predict house prices
8. Evaluate model performance

## 📊 Evaluation Metrics

* MAE – Mean Absolute Error
* MSE – Mean Squared Error
* RMSE – Root Mean Squared Error
* R² Score

## 🎯 Key Learning

This project provided practical experience with **supervised machine learning, regression analysis, feature selection, model training, prediction, and performance evaluation**.

## 🚀 How to Run

```bash
pip install pandas numpy matplotlib scikit-learn jupyter
jupyter notebook
```

Open the project notebook and run the cells sequentially.
